## 🚀 Getting Started

To run this portfolio locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/naveenvasamsetti/portfolio-website.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
